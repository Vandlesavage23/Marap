# Suspected personal-data incident
1. Declare an incident; one commander. Preserve logs; do not delete anything.
2. Scope: which data (special data is field-encrypted; ID numbers/names are never stored in plain text), which time window.
3. Contain: revoke sessions (`accounts.revoke_all_sessions`), rotate keys (see restore-and-keys.md), deactivate staff.
4. Legal: notify the regulator within the statutory window (Uganda DPPA) and affected members — counsel decides wording.
5. Record in the incident log; review in a blameless post-mortem.
